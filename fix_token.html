5. اضغط على التوكن نفسه لنسخه تلقائياً (لا تنسخ الكلام اللي فوقه!)

🤖 GitHub Actions - النشر التلقائي

هذا اللي تقصده! GitHub Actions
يخلي GitHub ينشر لقناتك تلقائياً بدون سيرفر!

من جوالك:

  1. ادخل مستودعك: github.com/mohammed772370-web/Repository-name
  2. Settings → Secrets and variables → Actions
  3. New secret → Name: BOT_TOKEN → Value: التوكن الصحيح → Add
  4. New secret → Name: CHANNEL_ID → Value: @Trading_TOB → Add
  5. اذهب لـ Actions → Enable workflows
  6. اضغط "📱 نشر يدوي من الجوال" → Run workflow → Run
  7. خلال 30 ثانية ينشر في قناتك!
